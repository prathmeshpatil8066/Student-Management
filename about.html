About Our Project

Student Management System is a simple web-based project designed to manage student information.

This project is created for learning HTML, CSS, Git, GitHub and team collaboration.

Project Objectives

  • Manage student information
  • Maintain student attendance
  • Organize academic records
  • Learn software development teamwork

Technologies Used

  • HTML
  • CSS
  • Git
  • GitHub
